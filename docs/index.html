Known scope

The live endpoint is a Cloudflare Worker port of the Python semantics — not the FastAPI service itself. Its rate window and audit chain are global across all visitors (like a single-process deployment); the Python sidecar is per process. An empty allowlist is not strict default-deny in either implementation. A local hash chain is not independently anchored.

Demo endpoint ≠ production security control. Code inspection ≠ independent security audit.
