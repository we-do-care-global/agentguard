The Problem

Agents now send email, call APIs, move money, and interact with wallets — with almost no governance layer. There is no standard answer to: What is this agent allowed to do? What did it actually do? Who approved it? How do I kill it mid-run?

AgentGuard answers

  • YAML policy engine (allow/deny tools, cap spend, limit tokens)
  • Tool-call proxy for LangChain, LangGraph, MCP
  • Append-only audit log — every action, queryable
  • Human-in-the-loop approval queue
  • One-click kill switch per agent

Features

Policy Engine

YAML-based allow/deny lists, spend caps, token limits. Load at startup; enforce at every tool call.

Audit Log

Append-only SQLite/SQLAlchemy log. Query by agent, tool, decision, or approved-by.

Approval Queue

Denied actions route to a human-in-the-loop queue. Approve or deny with a single call.

Kill Switch

Per-agent kill switch stops execution immediately — no partial state corruption.

Docker Compose

FastAPI + PostgreSQL + Redis in one command. Ready for production.

CLI + API

Typer CLI (init, run) and FastAPI endpoints (/toolcall, /audit).

Quickstart

# Install
pip install agentguard

# Init policy
agentguard init --agent research-bot

# Run server
agentguard run --policy policy.yaml

Docker: docker compose up -d — API at http://localhost:8000
